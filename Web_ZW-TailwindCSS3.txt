Installation Guide TailwindCSS 3

1. Installation Cli
>> npm install -D tailwindcss@3

    how to Uninstall
    >> npm uninstall tailwindcss


2. Configuration Cli for file: tailwind.config.json & postss.config.css
>> npx tailwindcss init -p

3. Linked .html file to Content[] in file: tailwind.config.js
    ['./index.html'] or ['./public/index.html']

4. Add input directive CSS for input file [input.css] / [tailwind.css]
->  @tailwind base;
    @tailwind components;
    @tailwind utilities;

5. Create CSS Style for file: style.css
   Cli command running directive css file: [input.css] / [tailwind.css] to compile file output: [style.css] in realtime for .html 
>> npx tailwindcss -i ./src/tailwind.css -o ./css/style.css --watch
